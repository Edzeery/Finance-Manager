# 📋 FMZS — قائمة التحقق اليدوي

> **الهدف:** التحقق من جاهزية المنصة للإطلاق من منظور الإدارة والمستخدم.
> يتم تنفيذ القائمة كاملة على بيئة **staging** ثم **production**.

---

## 🗂️ super-admin.tab_admin_panel

---

### ✅ لوحة الإدارة | 1. البيئة والإعدادات

- [ ] APP_ENV=production -- APP_DEBUG=false
    > تأكد من APP_ENV=production و APP_DEBUG=false في .env. شغّل php artisan config:cache. تحقق عبر route /api/health أو tinker.
- [ ] SESSION_DRIVER=database|redis + SESSION_SECURE_COOKIE=true
    > تأكد من SESSION_DRIVER=database|redis و SESSION_SECURE_COOKIE=true في .env. تحقق من جدول sessions إن كنت تستخدم database driver.
- [ ] QUEUE_CONNECTION=database
    > تأكد من QUEUE_CONNECTION=database في .env. افحص config/queue.php. شغّل php artisan queue:work --once لاختبار المعالجة.
- [ ] SSL/HTTPS مفعل
    > افتح الموقع عبر https://. تحقق من القفل الأخضر. استخدم ssllabs.com لفحص الشهادة.
- [ ] php artisan optimize ← دون أخطاء
    > شغّل php artisan optimize. يجب ألا يظهر خطأ. تأكد من أن cache مجلداتها قابلة للكتابة.
- [ ] مجلدات storage/ و bootstrap/cache/ قابلة للكتابة
    > شغّل php artisan storage:link إن لم يكن بعد. تأكد من صلاحيات الكتابة.
- [ ] CRON الجدول الزمني مفعل: * * * * * php artisan schedule:run
    > أضف السطر إلى crontab. تأكد بتشغيل crontab -e كمستخدم www-data.
- [ ] مفاتيح API حقيقية في .env (Chargily, Mail, Sentry...)
    > تأكد من وجود مفاتيح حقيقية لـ: CHARGILY_API_KEY, MAIL_MAILER, MAIL_HOST, MAIL_USERNAME, MAIL_PASSWORD, SENTRY_LARAVEL_DSN.

### ✅ لوحة الإدارة | 2. إدارة المستخدمين

- [ ] عرض قائمة المستخدمين مع البحث والتصفية
    > اذهب إلى super-admin → المستخدمين. تظهر القائمة مع: الاسم، البريد، الحالة، تاريخ التسجيل. استخدم البحث والتصفية.
- [ ] إنشاء مستخدم جديد مباشرة من لوحة الإدارة
    > اضغط "إضافة مستخدم". أدخل البيانات (الاسم، البريد، كلمة المرور، الدور). حفظ ← يُنشأ المستخدم دون الحاجة لتأكيد البريد.
- [ ] تعديل بيانات المستخدم (الاسم، البريد، الدور)
    > اختر مستخدم من القائمة. عدّل الاسم، البريد، الدور. حفظ ← تتحدّث البيانات.
- [ ] تعليق/تفعيل حساب المستخدم
    > اختر مستخدم نشط ← علّق. لا يستطيع تسجيل الدخول. فعّل مرة أخرى ← يعود طبيعياً.
- [ ] حذف مستخدم (ناعم + نهائي)
    > احذف مستخدم ← soft delete. تحقق من سلة المهملات. حذف نهائي ← يُزال بالكامل.
- [ ] تصفية المستخدمين (الحالة، الدور) + بحث بالاسم/البريد
    > فلتر حسب الحالة (نشط/موقوف). بحث بالبريد الإلكتروني. يمكن الجمع.
- [ ] عرض تفاصيل المستخدم (الاشتراكات، مساحات العمل، النشاط)
    > اختر مستخدم. تظهر تفاصيل: البريد، تاريخ التسجيل، الأدوار، مساحات العمل، الاشتراكات، آخر نشاط.
- [ ] تسجيل الدخول كمستخدم (Impersonate)
    > اختر مستخدم ← "تسجيل الدخول كـ". يُنقل إلى واجهة المستخدم. شريط علوي يظهر "أنت تستخدم حساب ...". خروج ← العودة للإدارة.

### ✅ لوحة الإدارة | 3. إدارة مساحات العمل

- [ ] عرض قائمة مساحات العمل مع البحث
    > اذهب إلى super-admin → مساحات العمل. تظهر القائمة مع: الاسم، المالك، عدد الأعضاء، الحالة، الاشتراك.
- [ ] عرض تفاصيل مساحة العمل (الأعضاء، الاشتراك، المعاملات)
    > اختر مساحة عمل. تظهر: الأعضاء، الاشتراك الحالي، عدد المعاملات، تاريخ الإنشاء.
- [ ] تعليق مساحة عمل ← منع الوصول
    > علّق مساحة عمل. يحاول أعضاؤها الدخول — يُمنعون مع رسالة "مساحة العمل معلقة".
- [ ] إعادة تفعيل مساحة عمل موقوفة
    > فعّل المساحة المعلقة. يعود الأعضاء للوصول الطبيعي.
- [ ] تصفية مساحات العمل (الحالة، الخطة) + بحث
    > فلتر حسب الحالة (نشط/موقوف) أو الخطة. بحث بالاسم.
- [ ] عرض إحصائيات مساحة العمل (عدد المعاملات، الإيرادات، المصروفات)
    > في صفحة التفاصيل، تظهر إحصائيات: عدد المعاملات هذا الشهر، إجمالي الإيرادات/المصروفات.
- [ ] حذف مساحة عمل + جميع بياناتها
    > احذف مساحة عمل. تُحذف جميع المعاملات المرتبطة (الأصول، الإيرادات، المصروفات...). soft delete مع إمكانية الاستعادة.

### ✅ لوحة الإدارة | 4. إدارة الباقات والخطط

- [ ] عرض قائمة الباقات مع المميزات والأسعار
    > اذهب إلى super-admin → الباقات. تظهر الباقات مع ترتيب العرض، الحالة (نشط/غير نشط)، الأسعار لكل عملة.
- [ ] إنشاء باقة جديدة (الاسم، الوصف، السعر، المميزات)
    > اضغط "إضافة باقة". أدخل الاسم، الوصف، slug. أضف الأسعار (شهري/سنوي لكل عملة). اختر المميزات وقيمها. حفظ.
- [ ] تعديل الباقة (الاسم، السعر، المميزات، الترتيب)
    > عدّل اسم الباقة، الوصف، الترتيب. عدّل الأسعار في plan_prices. أضف/أزل مميزات في plan_plan_feature.
- [ ] تفعيل/إلغاء تفعيل باقة
    > ألغِ تفعيل باقة ← لا تظهر للمستخدمين في onboarding. فعّلها ← تظهر.
- [ ] إخفاء/إظهار الباقة للجمهور
    > اجعل الباقة غير عامة ← لا تظهر في landing page لكن تظهر في لوحة الإدارة.
- [ ] إدارة مميزات الباقة عبر الجدول الوسيط (قيمة، ترتيب)
    > عدّل قيمة ميزة (مثل users=10). غيّر ترتيب العرض. أضف ميزة جديدة باقة. احذف ميزة.
- [ ] إدارة أسعار الباقة لكل عملة وفترة
    > أضف سعراً لـ EUR (شهري). عدّل سعر DZD (سنوي). احذف سعراً.
- [ ] تغيير ترتيب عرض الباقات
    > غيّر sort_order لباقة. يظهر الترتيب الجديد في onboarding والـ landing page.
- [ ] إدارة تعريفات المميزات (PlanFeature CRUD)
    > اذهب إلى المميزات. أضف ميزة جديدة (slug, name). عدّل ميزة. احذف ميزة (تأثيرها على الباقات المرتبطة).
- [ ] حذف باقة
    > احذف باقة. الاشتراكات المرتبطة تبقى لكن بعلاقة مقطوعة. يجب تأكيد الحذف.

### ✅ لوحة الإدارة | 5. إدارة الاشتراكات

- [ ] عرض جميع الاشتراكات مع التصفية (الحالة، الخطة، الفترة)
    > اذهب إلى super-admin → الاشتراكات. تظهر كل الاشتراكات. فلتر حسب: نشط، منتهي، ملغي، past_due. فلتر حسب الباقة. بحث باسم مساحة العمل.
- [ ] عرض تفاصيل الاشتراك (الفاتورة، المدفوعات، التواريخ)
    > اختر اشتراكاً. تظهر: الباقة، المدة، تاريخ البدء/الانتهاء، المدفوعات المرتبطة، الفواتير، حالة التجديد التلقائي.
- [ ] تفعيل اشتراك يدوياً من لوحة الإدارة
    > اختر اشتراك past_due. اضغط "تفعيل". يصبح Active دون دفع. تُنشأ فاتورة.
- [ ] إلغاء اشتراك يدوياً
    > اختر اشتراك Active. اضغط "إلغاء". يصبح Canceled مع canceled_at.
- [ ] تغيير باقة الاشتراك من الإدارة
    > اختر اشتراك. غيّر الباقة. يُحسب proration إن لزم. تُنشأ فاتورة.
- [ ] عرض إحصائيات الاشتراكات (النشط، المنتهي، الإيرادات)
    > في صفحة الاشتراكات: عدد النشط، المنتهي، الملغي. إجمالي الإيرادات الشهرية/السنوية.
- [ ] تصدير الاشتراكات إلى Excel/CSV
    > زر التصدير. الملف يحتوي على: مساحة العمل، الباقة، الحالة، تاريخ البدء، تاريخ الانتهاء، المبلغ.
- [ ] تشغيل التجديد التلقائي يدوياً (subscriptions:renew)
    > شغّل php artisan subscriptions:renew. يجب أن يعالج الاشتراكات النشطة ذات auto_renew=true والتي ends_at خلال يوم واحد. تُنشأ دفعات جديدة. تُمَدّد تواريخ الاشتراك.
- [ ] تشغيل تذكير انتهاء الاشتراك (subscriptions:remind-expiry)
    > شغّل php artisan subscriptions:remind-expiry. يُرسل بريد تذكير للاشتراكات التي ستنتهي خلال 3-5 أيام. يُنشئ إشعارات داخلية للاشتراكات غير المجددة تلقائياً.

### ✅ لوحة الإدارة | 6. إدارة المدفوعات

- [ ] عرض جميع المدفوعات مع التصفية (الحالة، الطريقة، التاريخ)
    > اذهب إلى super-admin → المدفوعات. فلتر حسب: الحالة (pending, paid, failed, canceled)، طريقة الدفع، نطاق تاريخي. بحث بالمرجع/المعرف.
- [ ] عرض تفاصيل الدفعة (المبلغ، الرسوم، الاشتراك، المستخدم)
    > اختر دفعة. تظهر: المبلغ، العملة، طريقة الدفع، الحالة، الرسوم، الضريبة، الاشتراك المرتبط، المستخدم، البوابة.
- [ ] اعتماد دفع يدوي (قبول إثبات الدفع)
    > اختر دفعة يدوية (BaridiMob/RedotPay) بحالة pending. افحص الإثبات. اضغط "قبول". تصبح paid. يُفعّل الاشتراك. تُرسل الفاتورة.
- [ ] رفض دفع يدوي مع سبب
    > اختر دفعة يدوية pending. اضغط "رفض". أدخل سبب الرفض. تصبح failed. يُشعر المستخدم بالبريد.
- [ ] رد مبلغ (Refund) لدفعة مدفوعة
    > اختر دفعة paid. اضغط "رد المبلغ". يُحاول رد المبلغ عبر البوابة (إن كانت online). تسجل كـ refunded.
- [ ] عرض فاتورة الدفعة وتحميل PDF
    > اختر دفعة paid. اضغط "عرض الفاتورة". تظهر الفاتورة بالمبلغ، الضريبة، الرسوم. حمّلها PDF.
- [ ] عرض إحصائيات المدفوعات (الإيرادات، عدد المعاملات)
    > في صفحة المدفوعات: إجمالي الإيرادات (شهر/سنة/كل)، عدد المدفوعات الناجحة/الفاشلة/المعلقة.
- [ ] تصدير المدفوعات إلى Excel/CSV
    > زر التصدير. الملف يحتوي على: المعرف، المرجع، المبلغ، العملة، الطريقة، الحالة، التاريخ.

### ✅ لوحة الإدارة | 7. إدارة بوابات الدفع

- [ ] عرض قائمة بوابات الدفع (النشطة/غير النشطة)
    > اذهب إلى super-admin → بوابات الدفع. تظهر البوابات مع: الاسم، المفتاح، الحالة، العملات المدعومة.
- [ ] تفعيل/إلغاء تفعيل بوابة دفع
    > عطّل بوابة Chargily ← تختفي من خيارات الدفع للمستخدم. فعّلها ← تظهر.
- [ ] تعديل بيانات اعتماد البوابة (API keys, Mode)
    > عدّل CHARGILY_MODE من test إلى live. غيّر المفاتيح. حفظ ← تُستخدم في الدفعات الجديدة.
- [ ] إدارة العملات المدعومة للبوابة
    > أضف/احذف العملات المدعومة لبوابة معينة. تظهر العملات المتاحة للمستخدم حسب البوابة المختارة.
- [ ] إدارة رسوم البوابة والضرائب المرتبطة
    > اربط ضريبة ببوابة. تظهر في تحليل السعر: gateway_fee و tax_added و tax_disclosed.
- [ ] اختبار اتصال البوابة
    > اضغط "اختبار الاتصال" لبوابة. تظهر رسالة نجاح/فشل.

### ✅ لوحة الإدارة | 8. إدارة الكوبونات

- [ ] عرض قائمة الكوبونات مع البحث
    > اذهب إلى super-admin → الكوبونات. تظهر القائمة مع: الكود، النوع، القيمة، الاستخدام، الصلاحية.
- [ ] إنشاء كوبون خصم (نسبة/قيمة ثابتة)
    > أضف كوبون: الكود، النوع (percentage/fixed)، القيمة، الحد الأدنى للمبلغ، الحد الأقصى للاستخدام، تاريخ الصلاحية. حفظ.
- [ ] تعديل كوبون
    > عدّل قيمة الخصم، تاريخ الصلاحية، الحد الأقصى. حفظ ← التغييرات تسري على الاستخدامات الجديدة.
- [ ] تفعيل/إلغاء تفعيل كوبون
    > عطّل كوبون ← لا يمكن استخدامه في الدفع. فعّله ← يعود للعمل.
- [ ] تقييد كوبون ببوابة دفع محددة
    > اربط الكوبون بـ Chargily فقط. اختبره مع BaridiMob ← يُرفض.
- [ ] تقييد كوبون بباقة محددة
    > اربط الكوبون بباقة Professional. اختبره مع Business ← يُرفض.
- [ ] عرض إحصائيات استخدام الكوبون
    > اختر كوبون. يظهر: عدد مرات الاستخدام، إجمالي الخصم الممنوح، آخر استخدام.

### ✅ لوحة الإدارة | 9. إدارة الضرائب والرسوم

- [ ] عرض قائمة الضرائب والرسوم
    > اذهب إلى super-admin → الضرائب. تظهر: الاسم، النسبة، النوع (gateway_fee/tax_added/tax_disclosed).
- [ ] إنشاء ضريبة/رسوم جديدة
    > أضف: الاسم، النسبة المئوية، النوع (رسوم بوابة/ضريبة مضافة/ضريبة مفصح عنها). حفظ.
- [ ] ربط ضريبة ببوابة دفع
    > اربط ضريبة 2.5% بـ Chargily كـ gateway_fee. تظهر في تحليل السعر عند اختيار Chargily.
- [ ] تعديل وحذف ضريبة
    > عدّل النسبة. احذف الضريبة — تُزال من البوابات المرتبطة.
- [ ] اختبار حساب الضريبة بدقة
    > أنشئ ضريبة 19%. اختر خطة بسعر 1000 DZD. تحقق من تحليل السعر: الضريبة = 190 DZD.

### ✅ لوحة الإدارة | 10. الأدوار والصلاحيات

- [ ] عرض قائمة الأدوار (منصة)
    > اذهب إلى super-admin → الأدوار. تظهر الأدوار: super_admin, admin, user مع صلاحيات كل دور.
- [ ] إنشاء دور جديد مع صلاحيات محددة
    > أضف دوراً جديداً. اختر الصلاحيات من القائمة (users.manage, workspaces.view, payments.refund...). حفظ.
- [ ] تعديل صلاحيات دور
    > عدّل صلاحيات دور admin — أضف/أزل صلاحية. المستخدمون بهذا الدور يتأثرون فوراً.
- [ ] تخصيص دور لمستخدم
    > اذهب للمستخدم → عدّل الدور. يكتسب صلاحيات الدور الجديد فوراً.
- [ ] التحقق من صلاحية المستخدم
    > اجعل دوراً بدون صلاحية payments.approve. مستخدم بهذا الدور لا يرى زر القبول في المدفوعات.
- [ ] حذف دور
    > احذف دوراً. المستخدمون بهذا الدور يُنقلون إلى الدور الافتراضي.

### ✅ لوحة الإدارة | 11. الإعدادات العامة

- [ ] تعديل الإعدادات العامة (اسم التطبيق، اللغة، التسجيل)
    > اذهب إلى super-admin → الإعدادات. غيّر اسم التطبيق. عدّل اللغة الافتراضية. فعّل/عطّل التسجيل. حفظ ← التغييرات تظهر فوراً.
- [ ] إعدادات الترجمة (اللغة الافتراضية، العملة، التنسيق)
    > عدّل العملة الافتراضية إلى USD. غيّر تنسيق التاريخ. حفظ.
- [ ] تعديل حدود السرعة (Rate Limits)
    > غيّر RATE_LIMIT_API من 120 إلى 60. أرسل طلبات سريعة — يُمنع بعد 60 طلباً.
- [ ] وضع الصيانة (Down for Maintenance)
    > فعّل وضع الصيانة. المستخدمون العاديون يرون صفحة الصيانة. المسؤول يرى الموقع طبيعياً.
- [ ] إعدادات البريد الإلكتروني
    > عدّل MAIL_MAILER. اختبر إرسال بريد تجريبي. يصل البريد.
- [ ] إعدادات الفواتير (ترقيم، شروط)
    > عدّل تنسيق رقم الفاتورة. عدّل شروط الدفع. حفظ ← الفواتير الجديدة تستخدم الإعدادات الجديدة.

### ✅ لوحة الإدارة | 12. الإعلانات

- [ ] عرض قائمة الإعلانات
    > اذهب إلى super-admin → الإعلانات. تظهر القائمة مع: العنوان، الحالة (منشور/مسودة)، التاريخ.
- [ ] إنشاء إعلان جديد
    > أضف إعلاناً: العنوان، المحتوى، الحالة (منشور/مسودة)، تاريخ النشر. حفظ.
- [ ] نشر إعلان ← يظهر للمستخدمين
    > غيّر حالة الإعلان إلى "منشور". يظهر الإعلان في لوحة المستخدم (بanner أو popup).
- [ ] تعديل وحذف إعلان
    > عدّل محتوى الإعلان. احذفه — يختفي من واجهات المستخدم.

    > سجّل كمستخدم عادي. تظهر الإعلانات المنشورة في dashboard أو صفحة الإشعارات.
